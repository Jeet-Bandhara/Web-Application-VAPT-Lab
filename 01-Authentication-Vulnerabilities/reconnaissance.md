##  Reconnaissance

The assessment began with reconnaissance of the OWASP Juice Shop application running locally at:

http://127.0.0.1:3000

### Application Discovery

The application was manually explored to identify authentication-related functionality and API endpoints.

The following areas were identified:

- User registration
- User login
- Forgot password / password reset
- User profile and session functionality
- Authentication-related REST API endpoints
- JWT-based authentication

### Tools Used

- Burp Suite Community Edition
- Browser Developer Tools
- OWASP Juice Shop
