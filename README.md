# Web Application VAPT Lab

A practical web application security assessment portfolio covering
common web vulnerabilities, reconnaissance, exploitation, impact
assessment, remediation, and professional security reporting.

## Objectives

- Develop practical web application penetration testing skills
- Understand common web vulnerabilities
- Practice manual vulnerability discovery
- Learn professional VAPT methodology
- Develop security assessment reports
- Document findings and remediation recommendations

## Methodology

The assessments follow a simplified penetration testing workflow:

1. Reconnaissance
2. Enumeration
3. Attack Surface Mapping
4. Vulnerability Identification
5. Validation
6. Exploitation
7. Impact Assessment
8. Remediation
9. Reporting
